              临时环境变量回退
              

                
若系统安全存储暂时不可用，可在启动 Dashboard 的同一终端临时提供内置 DeepSeek 的 API Key：

                
export DEEPSEEK_API_KEY="你的 API Key"
./start-acm-web.sh

                
环境变量仅对当前 shell 及其子进程生效。此回退不会持久化密钥；修复或解锁系统安全存储后，可继续使用上方表单保存。
