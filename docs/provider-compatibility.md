# Provider 接入与兼容说明

默认表单填写**显示名称、Base URL、API Key**。协议默认为自动；高级设置可以指定协议、鉴权头、非敏感协议头及模型 ID。凭据保存在系统安全凭据库，不写入配置或检测报告。

## 接入流程

1. 输入公网 HTTPS 地址：根地址、API 前缀和 `/chat/completions`、`/responses`、`/messages` 完整端点均可。保留自定义前缀，不跳转其他主机。
2. 保存并检测；自动发现模型和识别协议。单模型自动验证，多模型选择后验证，不批量测试整个目录。
3. 没有模型列表时连接显示“待补充模型”，在高级设置填写供应商提供的模型 ID。认证失败应修正 Key 或鉴权选项。
4. 刷新成功后自动删除目录中已下架的发现模型，保留手填模型；目录请求失败时保留原列表。引用已删除模型的任务需重新选择模型，不自动切换。
5. 初次使用任务时自动验证对应能力。更换协议、地址、凭据或兼容参数后需要重新验证；已有编辑失败会恢复旧连接。

接入检测共享 12 次 HTTP 请求、120 秒上限。任务验证共享该任务的请求数、时间及已知 Token 预算。预算不足或上游暂时故障可以稍后重试，不能保证任意服务和模型都可用。

## 兼容矩阵

| 能力 | Chat Completions | Responses | Anthropic Messages |
|---|---|---|---|
| 模型发现 | `/models` | `/models` | `/models`，支持分页 |
| 鉴权 | Bearer／指定 Key Header | Bearer／指定 Key Header | 默认 `x-api-key`，可选 Bearer |
| 文本与流式 | 支持 | 支持 | 支持，独立 SSE 状态机 |
| 原生结构化输出 | JSON Schema／JSON Object | JSON Schema／JSON Object | `output_config.format` |
| 缺原生 JSON | 提示词 JSON＋业务校验 | 同左 | 同左 |
| 不支持流式 | 缓冲为一次性回复 | 同左 | 同左 |
| 缺少 usage | 可用，统计标为未知 | 同左 | 同左 |

六类任务：推荐、计划整理、计划生成、辅导、补丁和总结。所有结构化结果仍经过业务校验；截断或无效数据不能应用或进入结果缓存。只对明确不支持的字段执行有限协商，认证、余额或服务故障不通过删参数掩盖。显式思考强度不会偷偷退回自动模式。

Anthropic 思考默认 `auto`，省略控制参数；支持的模型使用 adaptive effort 或手动预算。手动 low/medium/high 分别为 1024/4096/8192 tokens，输出预算须额外留出至少 1024 tokens。字段被接受只代表请求兼容，不代表能证明服务内部推理深度。

缺用量的请求不记为零消费；一次运行同时含有已知与未知用量时显示“部分未知”。总 Token 限制只能覆盖已知用量，请求数、截止时间和单次输出上限仍生效。不提供无法证实的费用或缓存命中率。

## 范围和验证

仅支持上述三种公网协议及既有 DeepSeek 专用适配器；不支持 HTTP、本地／内网地址、云平台 IAM、Gemini 原生协议或此轮之外的多模态与工具功能。需要特殊认证或额外字段的服务须在高级设置补充；非敏感头采用白名单，不允许把额外密钥藏在普通配置中。

回归覆盖真实适配器与内存 HTTP transport、三协议六任务矩阵、原生和兼容 JSON、原生和缓冲流、迁移、预算、凭证回滚及浏览器表单。模拟测试证明实现契约，真实服务验证结果另行报告，不代表所有上游供应商均已实测。

本轮真实验证：现有 Chat Completions 和 Responses 连接分别完成文本、JSON、流式及用量验证，各 3 次成功请求；成功轮分别报告 647 和 13,228 total tokens。Responses 先前受临时 12,000 Token 测试上限阻断，使用项目正常任务预算后通过，未放宽生产预算。Anthropic 没有已配置的真实连接，当前证据为适配器及 72 组合任务矩阵测试，尚未完成真实调用验证。
